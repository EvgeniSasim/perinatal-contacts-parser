# План: парсер контактов перинатальной инфраструктуры РФ

## Цель продукта

Собрать, нормализовать и отдать через API/UI публичные контакты учреждений:

- перинатальные центры (городские клинические, областные);
- женские консультации;
- родильные дома;
- клиники акушерства и гинекологии;
- кафедры акушерства и гинекологии;
- НМИЦ акушерства и гинекологии (как сущность и как привязка).

Данные должны быть доступны для сайта (в т.ч. WordPress): поиск, фильтры, Excel, подготовка массовой рассылки.

## Поля карточки учреждения

| Поле | Код API | Обязательность |
|------|---------|----------------|
| Название | `name` | да |
| Тип | `type` | да |
| Регион / субъект РФ | `region` | да |
| Город | `city` | да |
| Адрес | `address` | да |
| Телефон(ы) | `phones[]` | желательно |
| Email | `emails[]` | желательно |
| Сайт | `website` | опционально |
| ФИО главного врача | `chief_physician` | желательно |
| ФИО зав./зам. отделения патологии | `pathology_head` | опционально |
| Привязка к НМИЦ | `nmic_ref` | опционально |
| Источник / URL | `source_url` | да (аудит) |
| Дата обновления | `updated_at` | да |
| Статус проверки | `verification_status` | да |

Типы (`type`): `perinatal_center`, `perinatal_center_regional`, `perinatal_center_city`, `womens_clinic`, `maternity_hospital`, `obgyn_clinic`, `obgyn_chair`, `nmic`.

### Стек (рекомендация)

| Слой | Технология | Почему |
|------|------------|--------|
| API + парсер | Python 3.12, FastAPI, SQLAlchemy, Alembic | удобно для scrape + API в одном репо |
| Браузерный сбор | Playwright (+ httpx/BeautifulSoup для статики) | JS-сайты медучреждений |
| Очередь задач | Redis + Celery / ARQ | парсинг, экспорт, рассылка |
| БД | PostgreSQL | фильтры, FTS, дедуп |
| Admin UI | Next.js + простой table/search UI | управление и ручная правка |
| WP | плагин на REST + shortcode `[pnc_directory]` | встраивание на сайт |
| Экспорт | openpyxl / xlsxwriter | Excel |
| Рассылка | SMTP + адаптеры (Unisender/SendPulse) | массовые кампании без хранения писем в WP |
| Деплой | Docker Compose → VPS / Railway / Fly | один `compose` для API+DB+Redis+worker |
| CI | GitHub Actions | lint, test, build image |

### Источники данных (этапы)

1. **Seed-реестры** — открытые списки Минздрава/регионов, справочники НМИЦ, страницы субъектов РФ.
2. **Сайты учреждений** — добор телефона, email, ФИО главного врача.
3. **Ручная верификация** — админка: approve / reject / edit.
4. **Ре-краулинг** — периодическое обновление по `source_url`.

Юридически: только публичные страницы, robots.txt, rate-limit, User-Agent проекта, без обхода авторизации/CAPTCHA.

## API (контракт v1)

Базовый префикс: `/api/v1`

### Публичные (для WP / сайта)

- `GET /institutions` — список с пагинацией
  - query: `q`, `type`, `region`, `city`, `has_email`, `has_phone`, `nmic_ref`, `page`, `page_size`, `sort`
- `GET /institutions/{id}` — карточка
- `GET /meta/regions` — справочник регионов
- `GET /meta/types` — типы учреждений
- `GET /meta/stats` — счётчики

### Админ / интеграция (API key)

- `POST /admin/institutions` / `PATCH` / `DELETE`
- `POST /admin/jobs/crawl` — запуск парсинга
- `POST /admin/export` — Excel (async → download URL)
- `POST /admin/mailings` — создать кампанию из фильтра
- `GET /admin/mailings/{id}` — статус

Auth: `X-API-Key` (сайт/WP) + JWT для админки.

## Пользовательский интерфейс

### Admin UI (внутренний)

1. **Каталог** — таблица, поиск, фильтры по типу/региону/городу, бейджи полноты контактов.
2. **Карточка** — редактирование всех полей, история источников.
3. **Парсинг** — список источников, лог прогонов, ошибки.
4. **Экспорт** — «скачать Excel по текущему фильтру».
5. **Рассылки** — выбрать фильтр → шаблон письма → превью → отправка через провайдера / SMTP.
6. **API keys** — выдача ключей для WP.

### WordPress

- Shortcode: `[pnc_directory region="Москва" type="womens_clinic"]`
- Блок Gutenberg: поиск + фильтры + карточки
- Настройки плагина: URL API, API key, кэш TTL
- Опционально: кнопка «Экспорт» только для ролей admin/editor

## Массовая рассылка

- Не хранить SMTP-пароли в WP — только в backend.
- Кампания строится из **того же фильтра**, что и каталог.
- Обязательные защиты: unsubscribe-заглушка, rate limit, dry-run, лимит на тестовую отправку.
- MVP: экспорт Excel + CSV для внешней CRM; v2: SMTP/Unisender API.

## Риски

| Риск | Митигация |
|------|-----------|
| Сайты без структурированных контактов | ручная правка + приоритет официальных страниц |
| Дубликаты | нормализация адреса/телефона, fuzzy match |
| Юридические ограничения | только public HTML, opt-out рассылок |
| Нестабильная вёрстка источников | адаптеры на источник + тесты snapshot |
| WP кэш | TTL + purge endpoint |
