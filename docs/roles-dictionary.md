# Словарь должностей

Используется в `person_extractor` для определения `role` по тексту должности.

## Роли

| `role` | Значение | Паттерны (regex, case-insensitive) |
|--------|----------|-----------------------------------|
| `chief` | Главный врач / руководитель | `главн\w+\s+врач`, `и\.?\s?о\.?\s+главн\w+\s+врача`, `директор` (если нет `заместител`), `начальник\s+(центра\|учреждения)`, `руководитель\s+центра` |
| `deputy` | Заместитель главного врача | `заместител\w+\s+главн\w+\s+врача`, `зам\.?\s*главн\w+\s+врача`, `заместител\w+\s+директора` |
| `pathology_head` | Зав. отделением патологии | `заведующ\w+` **и** `патолог` в том же блоке |
| `head` | Зав. другим отделением | `заведующ\w+`, `начальник\s+отделения` |
| `other` | Прочее | всё остальное с ФИО |

Приоритет при конфликте в одном блоке: `deputy` > `chief` (строка «заместитель главного врача» содержит подстроку «главного врача», поэтому сначала проверяем `deputy`).

## Отделение патологии — варианты названий

- отделение патологии беременности
- отделение патологии беременных
- ОПБ
- акушерское отделение патологии беременности
- отделение патологии беременности и родов
- отделение патологии новорождённых *(другое отделение, но тоже «патология» — фиксировать `department`, чтобы отличать)*

Регулярное выражение: `отделени\w*\s+патологии|патологии\s+беременн|\bОПБ\b`

## Антипаттерны (не брать в `chief` / `pathology_head`)

| Контекст | Причина |
|----------|---------|
| «Наши специалисты», «Врачи», «Персонал» | рядовые врачи, не руководство |
| «врач-акушер-гинеколог», «врач-неонатолог» без «заведующий» | должность специалиста |
| «главный внештатный специалист» | должность в минздраве, не главврач учреждения |
| «главный бухгалтер», «главная медицинская сестра» | содержит «главн», но не врач |
| «заместитель главного врача по …» в списке из 6 человек | все `deputy`, ни один не `chief` |
| Отзывы, новости, «записаться к врачу» | текст не про руководство |

Явный список исключений для `chief`: `бухгалтер`, `медицинск\w+ сестр`, `внештатн`, `по\s+кадрам` без «врача».

## Уровни достоверности

| `confidence` | Условие | Куда попадает |
|--------------|---------|---------------|
| `high` | ФИО и должность в одном структурном блоке (`tr`, `li`, карточка, абзац) **и** страница классифицирована как «Руководство»/«Администрация» | в поля `chief_physician` / `pathology_head` |
| `medium` | ФИО и должность в одном блоке, но страница — «Контакты» или «Отделения» | в поля, если нет `high` |
| `low` | ФИО без должности в блоке, роль угадана по соседнему тексту | только в `institution_persons`, в поля **не** пишется |

## Формат ФИО

| Вид | Regex | Нормализация |
|-----|-------|--------------|
| Полное | `[А-ЯЁ][а-яё]+(-[А-ЯЁ][а-яё]+)?\s+[А-ЯЁ][а-яё]+\s+[А-ЯЁ][а-яё]+(ович\|евич\|ьевич\|овна\|евна\|ична\|инична)` | хранить как есть |
| Инициалы после | `[А-ЯЁ][а-яё]+\s+[А-ЯЁ]\.\s?[А-ЯЁ]\.` | «Иванов И.И.» |
| Инициалы до | `[А-ЯЁ]\.\s?[А-ЯЁ]\.\s?[А-ЯЁ][а-яё]+` | переставить в «Иванов И.И.» |

Перед сопоставлением: внутри блока схлопнуть все пробелы и переводы строк в один пробел (ФИО часто разорвано `<br>`).
